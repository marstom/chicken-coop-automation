
# Summary

This is home automation monorepo. It contains:
- chicken-coop:
    - ESP32 based chicken coop temperature, humidity amonia level monitoring system.

- chicken-coop-android-app:
    - Android application for chicken coop monitoring system. WIP


# How to start:
    - Install PIO for VS Code
    - Install mkdocs for documentation
    - Run live documentation server with `make run_docs` command
